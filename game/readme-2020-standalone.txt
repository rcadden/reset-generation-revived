Приветствую. Для веба существовал порт N-gage игры Reset Generation, сайт которого ныне мёртв. Но мы (я (@curoviyxru) вместе с @bodyz и @bs0dd) смогли его заставить работать и сейчас, но уже без браузера. Скачать можно по ссылке: https://curoviyx.ru/ResetGeneration-Standalone.zip

Примечание: Игра работает на Windows и Mac OS X, под Linux мы не смогли найти библиотеки игры. В архиве в комплекте имеется Java 7 x86 для Windows. Запускать игру нужно с помощью start.bat. Игру можно запустить и при помощи своей JRE, но игра запускается только с помощью Java для x86.

ВНИМАНИЕ: В пути игры не должно быть русских букв и спецсимволов.

Обновлено: изменено увеличение окна игры.

Онлайн-режим не работает.

Аргументы:
-resize - позволяет ресайзить окно
-ratio=N - ставит множитель размера окна, равному N

start.bat - запуск игры со встроенной JRE 6 x86.
start_x2.bat - запуск игры со встроенной JRE 6 x86 с -ratio=2.
start_x3.bat - запуск игры со встроенной JRE 6 x86 с -ratio=3.
start_x4.bat - запуск игры со встроенной JRE 6 x86 с -ratio=4.
start_resize.bat - запуск игры со встроенной JRE 6 x86 с -resize.
